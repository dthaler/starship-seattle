# starship-seattle
Artemis Cosmos Spaceship Bridge Simulator configuration files

This repository is organized as follows:

* StreamDeck directory: relevant only if you have a StreamDeck for Engineering
* JoyToKey directory: contains JoyToKey configuration files
* Cosmos: contains actual Cosmos configuration files
* ThalerDmx: contains DMX configuration specific to Dave Thaler's DMX equipment
* Desktop: contains other scripts useful to have on the desktop
