# Starship Seattle
Artemis Cosmos Spaceship Bridge Simulator configuration files

This repository is organized as follows:

* [StreamDeck directory](tree/main/StreamDeck): relevant only if you have a StreamDeck for Engineering
* [JoyToKey directory](tree/main/JoyToKey): contains JoyToKey configuration files
* [Cosmos directory](tree/main/Cosmos): contains actual Cosmos configuration files
* [ThalerDmx directory](tree/main/ThalerDmx): contains DMX configuration specific to Dave Thaler's DMX equipment
* [Desktop directory](tree/main/Desktop): contains other scripts useful to have on the desktop
